    <h3>DeepLNP: Multi-Modal LNP Formulation Property Prediction</h3>
    <p>I developed DeepLNP, a discriminative model for predicting LNP transfection efficiency, particle size, zeta potential, and cytotoxicity. The system integrates four-component molecular encoding, molar-ratio weighted MPNN fusion, cross-attention, MoE-style fusion, uncertainty-weighted multi-task learning, and feature-priority handling for incomplete data settings.</p>

  <article>
    <h3>AdaptiveGaitSegNet for Parkinson's Disease Gait Recognition</h3>
    <p>This project studies robust Parkinson's disease gait recognition with dual-branch feature extraction, local frame and global sequence modeling, focus convolution, edge-aware pooling, multi-scale pyramid pooling, residual feature fusion, and a joint triplet/cross-entropy loss.</p>
  </article>
  <article>
    <h3>Multi-Omics Graph Attention Network for Triple-Negative Breast Cancer</h3>
    <p>I developed a GAT-MLP prognostic framework integrating scRNA-seq, ATAC-seq, radiomics, CCA-aligned multimodal features, gene homology, PPIs, transcription-factor networks, CellphoneDB communication analysis, pathway enrichment, and patient risk stratification.</p>
  </article>
  <article>
    <h3>Tea Plant Pest and Disease Knowledge Extraction</h3>
    <p>I co-authored a BERT-BiLSTM-CRF named entity recognition method for tea plant pest and disease text. The project built a domain dataset, constructed a Neo4j knowledge graph, and supported an intelligent question-answering system for agricultural decision support.</p>
  </article>
  <article>
    <h3>Vehicle Trajectory Prediction with GraphWaveNet and TiDE</h3>
    <p>This project uses adaptive graph convolution to learn dynamic dependencies among vehicle entities and environmental factors, then fuses generated predictors with trajectory time-series features through a Time Series Dense Encoder for interpretable trajectory prediction.</p>
  </article>
  <article>
    <h3>Fault Wave Analysis for Industrial Substations</h3>
    <p>I worked on CNN-based closing-resistor fault identification using Hilbert-Huang Transform spectrograms, a seven-layer CNN architecture, adaptive learning-rate adjustment, regularization, and PSCAD/EMTDC simulation validation under practical operating conditions.</p>
